# show-me

Help the user understand the current topic with the smallest useful visual: concise diagrams, code-shape sketches, diffs, Mermaid, or a focused HTML artifact.

## Usage

Invoke `/show-me` in Claude Code or `$show-me` in Codex with the topic or question to explain.
