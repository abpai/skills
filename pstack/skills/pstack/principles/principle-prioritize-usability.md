# Prioritize usability

When a product, UX, or feature-scope tradeoff must be made:

- Favor the user's experience over implementation convenience.
- Justify every feature, control, and option by how it serves the main workflow.
  Remove what gets in its way.
- Prefer fewer polished features to more unfinished ones.
- Test uncertain design choices with a disposable prototype before production code.
- Get the details right: feedback, error states, transitions, alignment, and spacing.
- Give end users, API consumers, and code maintainers equal consideration.
  Explain the impact from their perspective.
- Let the experience set the goal; prerequisites determine the order of work.
