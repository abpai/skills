# /engineering:algorithm

Use the `algorithm` module to rework a plan with Elon Musk's five-step
first-principles algorithm.

1. Read `skills/engineering/algorithm.md`.
2. Run the five steps strictly in order. Gate on Step 1 (question the
   requirements) and Step 2 (delete); auto-apply Steps 3–5 (simplify,
   accelerate, automate); then gate once more on the final review.
3. If a question can be answered by inspecting the codebase, inspect it instead
   of asking the user.
