# visual-pr

Create or update a pull request with a compact visual outline for reviewers.
Invoke `/visual-pr` in Claude Code or `$visual-pr` in Codex on the current task.
Requires Git and an authenticated GitHub CLI (`gh`) with access to the target repository.

Adapted from [HumanLayer's visual-pr](https://github.com/humanlayer/skills/tree/main/plugins/visual-pr).
See [the sync record](../docs/humanlayer-sync.md) for provenance and compatibility changes.
